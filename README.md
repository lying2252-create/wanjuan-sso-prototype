# 万卷 SSO 产品交互原型

在线体验：https://lying2252-create.github.io/wanjuan-sso-prototype/

## 演示内容

- 系统管理 → 登录源管理：OIDC、SAML、LDAP/AD 三种配置及启停。
- 登录体验：根据已配置登录源展示入口，模拟企业认证和权限状态。
- 审批中心 → SSO 账号开通：配置部门和角色，审批后模拟创建账户。
- 需求说明：产品规则、异常状态与验收清单。

## 推荐演示流程

进入「登录体验」，使用测试账号 `zhangsan` 完成认证；在后台「审批中心」配置部门、角色并通过；再用相同测试账号登录验证。`wangwu` 为已开通样例。可通过右上角「演示场景」切换异常状态或重置数据。

## 运行与部署

直接打开 `index.html` 即可运行，无构建依赖。GitHub Pages 使用 `main` 分支根目录发布，后续修改提交后自动更新。

本项目为产品交互演示，数据保存于当前浏览器的 localStorage，不连接真实企业认证和业务服务，全部账号及配置均为虚拟样例。
